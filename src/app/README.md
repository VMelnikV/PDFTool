# PDF Tool — Вихідний код

Це папка з вихідним кодом застосунку PDF Tool.

## 🚀 Запуск

```bash
python3 main.py
```
## 📁 Структура

    main.py — точка входу

    launcher.py — перевірка залежностей

    pdf_tool.py — головне вікно

    tabs/ — вкладки (конвертація, об'єднання, розділення, форми, стиснення, все в одному)

    utils/ — допоміжні функції
