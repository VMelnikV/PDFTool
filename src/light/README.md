### 📁 Структура для збірки легкої версії

У папці `src/light/` зібрані файли легкої версії PDF Tool, які є тільки GUI-оболонкою без вбудованих скриптів.

Для збірки легкої версії:
1. Використовуйте файли з папки `src/light/`
2. **Додайте** відсутні файли з папки `src/full/` (наприклад, `pdf_tool.py`, папки `tabs/` та `utils/`)

> **Важливо:** Саме **додайте** відсутні файли, а не замінюйте ними наявні файли з `src/light/`!

### 📦 Встановлення

```bash
# Клонуйте репозиторій
git clone https://gitlab.com/MelnikV/pdf_tool.git
cd pdf_tool

# Встановіть залежності
pip install -r requirements/base.txt

# Запустіть легку версію
python3 src/light/main.py
```
