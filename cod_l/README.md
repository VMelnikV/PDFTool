### 📁 Структура для збірки легкої версії

В папці `cod_l` зібрані файли легкої версії PDFTool, які змінено та які відсутні у повній версії.

Для збірки легкої версії:
1. Клонуйте файли з папки `cod_l`
2. **Додайте** відсутні файли з папки `cod` (наприклад, `pdf_tool.py`, папки `tabs/` та `utils/`)

> **Важливо:** Саме **додайте** відсутні файли, а не замінюйте ними наявні файли з `cod_l`!
